# Attribution and media provenance

## Code lineage

Orbit adapts [Distance](https://github.com/Yiyi-philosophy/distance), retaining its graph, planet-rendering, scoring, and comet-travel foundation. The original [MIT license](LICENSE), including the Yiyi-philosophy copyright notice, remains intact.

The source shared for this deployment is [Yash-PoPularPlusPlus/orbit-friends-universe](https://github.com/Yash-PoPularPlusPlus/orbit-friends-universe). The public deployment and documentation are maintained in [13shreyansh/orbit-friends-universe](https://github.com/13shreyansh/orbit-friends-universe). Git history preserves the lineage; no authorship of the entire inherited application is claimed.

## AI-assisted work

Astra in Codex assisted the Orbit adaptation, story curation and corrections, implementation review, deployment, and verification. The team reports using GPT Image 2 to visualize the diary and broader experience. The [visual intelligence document](docs/VISUAL_INTELLIGENCE.md) records that account separately from model-run artifacts, which are not archived in the repository.

## Photographs

Friends stills and promotional images are demonstration reference material. Original records are preserved at:

- [Friends photo provenance](public/friends/provenance.json)
- [Pair-specific photo provenance](public/friends-pairs/provenance.json)
- [Prepared album index](public/friends/album.json)

Those records include source-page and image URLs and explicitly do not claim public-domain status or free redistribution rights. Some historical records contain temporary download paths or older URL prefixes. They are retained as historical records; the [current manifest](docs/evidence/assets.json) maps actual repository files and hashes.

The MIT license covers source code under its terms. It does not grant rights to the television imagery. Public accessibility of an image is not a license, and a SHA-256 hash is not a rights clearance. Use appropriately licensed or participant-owned photographs for a broader release.

## Other assets

The checked-in GLB models and background video are indexed in the same manifest. Their presence does not establish model-generation provenance. A per-file generation or license trail is still needed where the repository does not contain one. Procedural scene code and CSS styles are implementation artifacts, distinct from externally generated bitmap assets.
